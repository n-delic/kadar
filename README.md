# Kadar

A personal photo and video editor for Android: meme text, stickers, background removal, trim, speed and music. Offline, no subscription, no watermark.

- Build and install: see `CONTRIBUTING.md`
- How the code is organized and the rules for changing it: see `AGENTS.md`
- What's done and what's next: see `ROADMAP.md`

Fonts Anton and Plus Jakarta Sans are under the SIL Open Font License, icons are Material Symbols (Apache 2.0); licenses in `third_party/`.
